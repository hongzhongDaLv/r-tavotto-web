# R-Tavotto Web

基于 [Tavotto](https://github.com/Tavotto/Tavotto) 的非官方 R 绘图编辑器衍生版本。沿用上游画布选择、对象树、检查器和撤销交互，使用 WebR 在浏览器中运行 R/ggplot2。

[打开在线编辑器](https://hongzhongdalv.github.io/r-tavotto-web/) · [本次上线与验收报告](docs/RELEASE_REPORT_20261003.md)

网站定位是 **打开 R 图 → 在图上选对象 → 调整参数 → 得到可重放的 R 修改代码和图形导出**。浏览器版本使用文件选择器导入用户提供的文件；无需另起本机 Node/R 服务，站点也不会查询电脑上的目录列表。

## 使用流程

1. 打开网站。可以先用人工数据示例检查编辑流程，再导入自己的文件。
2. 从电脑选择 `.R` 绘图脚本及所需文件，或选择项目文件夹以保留相对路径；指定入口脚本并打开。此时初始化 WebR 与绘图包，首次下载速度取决于网络。
3. 脚本应产生 ggplot2 图对象；有多个对象时选择要编辑的对象。初始画幅采用该对象实际使用的 R 导出设备或 `ggsave()` 尺寸；没有声明或同一个对象有不同导出尺寸时，界面要求明确填写本次画布尺寸，不能猜一个预设值。
4. 按文件导入界面的提示补充依赖的数据或辅助文件。浏览器工作区不会自动访问原始脚本所在文件夹，`C:/...` 或 `E:/...` 路径也不会自动映射成浏览器文件。
5. 在画布或左侧对象树选中图元，右侧展示该对象的属性。修改后可查看相应 R 代码，使用撤销/重做核对变化。空白处左→右框选全包含对象，右→左窗交选相交对象，Shift 加选。
6. 下载 PNG/SVG/PDF、编辑代码或项目。原始 `.R` 文件保持不变。退出前请主动下载保存；浏览器工作区不能替代正式科研数据存档。

画布是后面的白色方格输出页面，图框是坐标轴围出的数据绘图区。编辑器只暴露这两类尺寸，位置/尺寸使用 px，R 的字体、点径、线宽等参数保留其原生单位。改画布只改变输出页面边界；改图框只改变数据绘图区几何，文字字号、点径和线宽保持原物理大小。图框可以移出画布，编辑视图保留超出页面的图元；有限尺寸的 PNG/PDF 导出仍以页面为边界。具体上线版本的验收证据见 [发布报告](docs/RELEASE_REPORT_20261003.md)。

## 保存和重开

编辑器将最近一个项目自动保存在当前浏览器的 IndexedDB 中，成功保存后显示状态；同一浏览器可从导入页继续。浏览器隐私模式、存储配额限制和清理站点数据可能使这种恢复不可用。

“下载项目”生成 `.tavotto-r.json`，包含用户已选择的脚本、数据文件、入口对象和交互修改，并校验文件哈希；再次选择该项目文件可重开。它是包含科研输入的本机文件，请按自己的数据共享规则保存或发送。只下载 `figure-edited.R` 时，仍需保留相应源脚本和数据，不能将它当作独立完整项目。

## 兼容范围

当前优先处理单个笛卡尔坐标 ggplot2 面板。复用的 UI 并不代表所有上游 Python 功能已经迁移到 R；patchwork/cowplot 组合图、复杂分面、任意第三方 geom、逐数据点操作和完整出版预检必须按具体实现与验证结果判断。不能安全拆分的图层保留图层级选择，不宣称每个数据点都已成为独立对象；不能适配的复杂对象应明确提示。

WebR 使用 WebAssembly R 包，不能直接加载电脑已安装的 Windows R 包或 DLL。仅在 WebR 包仓库有可用构建的依赖才能直接运行。字体和渲染设备也可能与本机 R 不同；论文图应对导出结果做实际核对。

使用者脚本仍负责数据清洗、统计模型和显著性计算。交互修改不会证明原始数据或统计分析正确。

## 隐私与文件

用户选择的文件进入浏览器的虚拟工作区；本站不提供用户文件上传到云端的后端。运行时、R 包和字体资源仍需网络下载，GitHub Pages/CDN 会接收到常规资源访问请求。用户 R 脚本自带的联网语句可能产生额外网络请求，详见 [网页隐私说明](docs/WEB_PRIVACY.md)。

本仓库不得包含 PSR、野火、财务或土样的真实数据、项目图和本机缓存。`.gitignore`、公开源码检查与静态包检查共同约束发布范围；公开示例必须使用人工数据或明确允许公开的材料。旧上游审计快照、生成记录和未经单独内容审阅的文档截图也不随这个独立发布仓库公开。

## 开发与构建

使用 Node **24.19.0** 与 pnpm **11.19.0**。依赖由 `web/pnpm-lock.yaml` 固定，源码许可证为 AGPL-3.0-only。

```sh
pnpm install:web
pnpm check:public
pnpm test:public
pnpm test:browser
pnpm build
pnpm preview
```

`pnpm build` 调用 `web/vite.browser.config.ts`，公开产物只有 `web/dist-browser/`。默认资源路径用于本地预览；发布本仓库时设置 `BROWSER_BASE_PATH=/r-tavotto-web/`。本次采用 **main 保存源码、gh-pages 保存已检查静态产物**；GitHub Pages 的 Source 选择“Deploy from a branch”，分支 `gh-pages`，目录 `/ (root)`。

构建生成 `build-info.json`，记录源提交及运行时类型，并附带许可证、衍生说明和隐私文档。发布时需设置 `GITHUB_REPOSITORY=hongzhongDaLv/r-tavotto-web` 与 `GITHUB_SHA=<本次源码提交>`，使产物指向对应公开源码。当前发布没有运行自定义 GitHub Actions 工作流；本机受检查构建与公网功能验收分别记录。WebR 固定为 `0.6.0`，浏览器通过 PostMessage 与其 Worker 通信，适用于不提供跨源隔离响应头的 GitHub Pages。

可选 Actions 工作流保留在 [docs/templates/pages.yml](docs/templates/pages.yml)。只有后续具备相应 GitHub workflow 授权、将其安装到 `.github/workflows/` 并切换 Pages Source 后，才会执行；它不参与本次分支发布。

构建命令不会把 `tests/browser-*-results/`、本机原生验证输出或历史截图报告上传；相应测试脚本和人工数据 fixture 保留在源码中。完整上游规则和架构文档保留作来源参考，它们描述的是上游系统，不代表本浏览器发行版已包含桌面、Python、Codex MCP 或云端 Agent 服务。
